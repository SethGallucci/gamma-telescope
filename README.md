# Gamma Telescope Data Pipeline & Web App

[![Open in Hugging Face Spaces](https://img.shields.io/badge/Hugging%20Face-Spaces-yellow?logo=huggingface&style=for-the-badge)](https://huggingface.co/spaces/seth-gallucci27/MAGIC-gamma-telescope)

A full-stack, cloud-native project designed to ingest, process, and visualize simulated Gamma Telescope data.

This repository houses the entire end-to-end architecture, including a mock data generator, an AWS/Databricks-based data processing pipeline, and a web application for end users. The Python dependencies are managed using [`uv`](https://www.google.com/search?q=%5Bhttps://github.com/astral-sh/uv%5D(https://github.com/astral-sh/uv)).

## Architecture & Features

- **Mock Data Ingestion:** Generates synthetic gamma-ray batch data.
- **Cloud Infrastructure (AWS):** Infrastructure configurations for storing and routing the data.
- **Data Processing (Databricks):** Jupyter notebooks and Databricks scripts for ETL, data transformation, and analytics.
- **Interactive Web App:** A web interface to view the processed telescope data/metrics using Hugging Face Spaces.
- **CI/CD:** Automated workflows powered by GitHub Actions.

## Prerequisites

Before you begin, ensure you have the following installed:

- **Python** (Check `.python-version` for the exact version)
- **[uv](https://github.com/astral-sh/uv)** for lightning-fast Python dependency management.
- **AWS CLI** (configured with appropriate IAM permissions).

## Setup & Installation

**1. Clone the repository:**

```bash
git clone https://github.com/SethGallucci/gamma-telescope.git
cd gamma-telescope
```

**2. Install dependencies:**
Because this project uses `uv`, you can quickly sync your virtual environment:

```bash
uv sync
```

## Usage

### 1. Generating Mock Data

To start emitting simulated gamma-ray data batches into your pipeline:

```bash
uv run python mock_data_source/main.py
```

### 2. Cloud & Data Processing

- **AWS:** Navigate to the `/aws` directory to deploy the necessary cloud resources.
- **Databricks:** The `/databricks` directory contains Jupyter Notebooks. These can be imported into your Databricks workspace to execute the ETL pipeline on the mock telescope data.

### 3. Running the Web App

Navigate to the web app directory to start the local server:

```bash
cd web_app
uv run streamlit run main.py
```

## Testing

To run the smoke test, execute:

```bash
uv run test_end_to_end.py
```
